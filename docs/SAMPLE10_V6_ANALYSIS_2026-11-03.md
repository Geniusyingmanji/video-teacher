改进优先级：

1. 评分必须分开任务完成、视频带来的信息和布局质量；严重缺陷不能由清晰编码和稳定静态图抵消。
2. 用真实最终静帧、冻结视频、局部标签揭示、无关装饰运动、错误时序及布局破坏建立正反对照。不能只测试 JSON 合法。
3. 检查可见的关系和变化：路径连通、箭头归属、对象身份守恒、每个槽位唯一实体；不能仅数标签和箭头。
4. 布局采用确定的标题、图示和注释区域，修改坐标前先静态布局预检；不让自由代码反复试错。

6. 保存所有候选和分阶段状态，评测故障同片复核，生成故障才修代码；提供“曾成功生成”“最终采用”“质量验收”三个口径。
