# 教学视频评分 v7：可读布局、过程证据与时间带来的信息

## 问题与研究依据

v6 固定十题最终只有 4 个有效结果，均值却为 97.88；192 项准则中 181 项满分。
复核发现“填对答案”“存在标签与箭头”和“画面编码清晰”经常被等同于优秀教学。
部分成片仍有排版拥挤、结构断开，以及最终截图几乎涵盖所有信息的问题。
历史分数保留，本次另建 `video-teacher-2x8-v7`。

我们查阅并引用以下 2026 年正式会议工作及作者公开说明，借鉴其高层研究原则：

| 公开来源 | 参考原则 | 本项目的具体设计 |
| --- | --- | --- |

## 原创实现与规则

`eval/instructional_video.py` 先独立审查，再比较实际视频和其实际最后一帧保持相同时长的版本。
比较以 A/B 和 B/A 两个次序运行。次序影响实质判定时保留不确定状态，禁止选有利一次。
若独立布局/表征或解释准则已明确失败，仍可记录有上界的低分拒绝，同时明确 comparison_valid=false；
没有其他明确失败依据时，整体评分无效。
这个“末帧对照”是时间信息的审查，不是实际受试者学习实验。

独立审查的六个准则：布局可读性、视觉解释、时间贡献、表征完整性、教学聚焦和可感知节奏。
各项锚点为 1=不可用/缺失，2=薄弱，3=基本完成，4=有强证据，5=有具体理由支持的特别优秀。
满足任务不自动获得满分；同时更新八轴提示中此前“5=clear success”的宽松定义。

每个实质事件需要前后帧、局部区域、实体状态及教学意义。初始画图、文字或答案揭示、
普通高亮归为 reveal；无关运动归为 decoration。operation、reasoning、comparison 才进入
过程证据候选。用实际采样像素检查所报局部区域是否存在可见中间状态；这只能证实局部
变化存在，不能证明语义正确。语义仍须审查及末帧对照共同支持。
局部阈值用于排除单像素噪声，不用全画面运动面积判断教学意义。

严重问题需要本地位置与证据帧。持续的关键文字遮挡、重叠、不可读，以及关系/状态破坏
阻止高分；单帧写字过程中的临时重叠不直接作为持续布局失败。

呈现原始分由六项等权映射到 0–100。最终呈现分取该分与布局、表征、视觉解释、
时间贡献四个核心分的最小值，并施加有原因的上限：

| 证据 | 呈现/总体上限或状态 |
| --- | --- |
| 持续关键布局/表征严重失败 | 最多 39，并不通过 |
| 没有像素支持的实质教学事件 | 最多 49，并不通过 |
| 核心视觉解释或时间贡献薄弱 | 最多 49，并不通过 |
| 两次对照均无法证明超出末帧的实质教学信息 | 最多 49，并不通过 |
| 对照结果不确定或顺序敏感 | 不得通过；若另有明确失败则保留有界拒绝，否则评分无效、数值为 null |
| 六项均至少 4、呈现分至少 70，且全部证据门槛通过 | 才能通过呈现验收 |

总体取“原八轴诊断总分、呈现分”的最小值；八轴原分和分组原分另存，不能用稳定图像、
清晰编码或其他高分掩盖薄弱布局及教学价值。生成、源图保护、任务覆盖、正确性等原门槛继续保留。
这些是本项目公开的初始工程规则；39/49/70 等阈值尚无独立人工校准，不能宣称来自论文或
声称是最优阈值。失败由具体证据和准则决定，不给本轮所有视频统一减分。

## 验证与诚实报告

1. 单元/集成回归检查：严重缺陷不能被满分抵消、静帧与装饰运动不能冒充过程、相关小区域
   真实过程不被全局低运动误杀、A/B 偏差及缺失审查不能通过、证据帧与坐标必须有效。
2. `scripts/build_scoring_controls.py` 编译自写排序场景，并生成六种控制：正确演示、同演示
   加持续重叠、冻结终帧、倒序、冻结图加无关运动、冻结图加很小的文字揭示。
3. `scripts/review_instructional_videos.py` 在真实接口上测试这些对照，并重看本轮实际成片。
   输出为独立呈现审查，旧 v6 总分只作为历史字段。没有重新调用八轴时绝不称为完整 v7 总分。
4. 未生成视频的题仍计入十题分母；布局拒绝的诊断视频可以单独审查，不能因此变成合格交付。

限制：同模型审查仍可能误判；交换 A/B 不等于独立模型；末帧基线未覆盖所有可能的最佳截图；
合成排序对照范围有限，也不等于独立人工校准或对 400 个任务的语义验证。
原图填空等任务可能有很高任务完成度，却天然缺少视频带来的信息。应分别报告，并在后续
题库修订中明确其定位，不能暗改原题要求或要求任意增加无关动画来刷分。
