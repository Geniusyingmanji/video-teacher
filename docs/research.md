# RISE-Teacher：视频生成 Agent、Code 与自演化调研

检索日期：2026-11-11。范围包括视频生成工作流、代码介入视觉生成、经验／技能演化，以及修改 Agent 自身执行机制的 RSI。下列机制来自原论文、正式论文页或作者项目页；论文报告的效果不等于本项目复现结果。本次重点核对方法设计，没有复现各论文排行榜。

**建议：保留 benchmark 优先，以“可验证教学状态 + 按错误类型局部修复”作为方法主轴，把跨题技能积累作为待验证扩展。现阶段可以称 code-assisted educational video agent；尚无证据称 RSI。**

## 1. 文献地图与直接竞争

### 视频制作与工具编排

| 工作及一手来源 | 关键机制 | 对我们的启发／区别 |
| --- | --- | --- |
| [Code2Video](https://proceedings.mlr.press/v306/chen26bx.html)，ICML 2026；初稿 2025-10 | Planner 编排时间分镜，Coder 写可运行 Python 并局部纠错，Critic 用视觉锚点连接画面问题与代码修改。 | 必须比较的直接基线。“Planner–Coder–Critic”本身已有。可沿用其生成思想，评测按我们的常规维度实施。 |
| [MovieAgent](https://arxiv.org/abs/2503.07314)，2025-03 | 电影、场景、镜头分层规划，多制作角色协作。 | 完整讲解应有整课目标、步骤与镜头时间表；单独拼接漂亮短片不保证讲解连续。 |
| [GenMAC](https://arxiv.org/abs/2412.04440)，2024-12 | 设计、生成、重设计闭环，把验证、建议、纠错等职责拆开。 | 先判断错误原因，再路由到对应修复工具；不必为所有维度重新生成全片。 |
| [MVAgent](https://arxiv.org/abs/2609.30609)，2026-09 | 带类型的生成条件、跨镜头状态记忆、空间参考，以及镜头级策略优化。 | 教学符号、对象身份、解题状态也要跨镜头一致；我们的优先对象是知识状态，不只是人物外观。 |
| [VideoGen-Agent](https://arxiv.org/abs/2609.24997)，2026-09；v4 2026-11-06 | 增强、生成、验证工具；SFT 后进行多任务 Agent RL。 | 后续可训练修复工具选择；当前先用冻结模型验证工具是否有效。该文 VABench 是视频生成工具使用 benchmark，勿与其他同名音视频评测混淆。 |
| [VideoWeaver](https://arxiv.org/abs/2606.08091)，2026-06；v2 2026-10 | 动态组合基础技能，联合检查执行过程与成片，再把经验更新为任务类别级技能。 | **直接覆盖“视频 Agent + 技能演化”**。只加记忆库或工作流更新不足以区分我们。 |
| [Google 长视频研究总览](https://www.research.google/blog/coherent-long-form-video-generation/)，2026-09 | 总览 Co-Director、CANVAS、A²RD、VQQA：全局规划、世界状态、长程拼接和反馈修复。 | 借鉴状态跟踪与局部修复；这里引用作者总览，不将四篇单独计作已深读的论文。 |

### 代码、状态与确定性渲染

| 工作及一手来源 | 关键机制 | 对我们的启发／区别 |
| --- | --- | --- |
| [ALGOGEN](https://aclanthology.org/2026.findings-acl.156/)，ACL Findings 2026 | 工具生成可验证算法轨迹，状态／操作与视觉样式分离，确定性渲染。 | **“状态与渲染分离”已有先例**。我们需要证明跨学科教学关系、原图约束及错误修复的具体价值。 |
| [CoCo](https://arxiv.org/abs/2603.08652)，2026-03 | Code-as-CoT：代码构建结构草图，图像模型完成外观。 | 符号、坐标和关系先计算；表现层可单独优化。该文主要是图像生成。 |
| [VideoCoCo](https://arxiv.org/abs/2607.27380)，2026-07 | Blender 可执行过程产生动态草稿，再做草稿条件视频编辑。 | 教学精确层与自然视觉层可以分工；生成式细化后仍需复查公式、箭头和轨迹。 |
| [Video-Coder](https://arxiv.org/abs/2611.09894)，2026-11-06 | Agent 写并执行动态 3D 场景代码；在执行／渲染环境内做 SFT 与 Agent RL，用草稿条件化下游视频生成。 | **最新直接竞争：代码草稿 + 视频生成 + Agent 训练已有。** 目前无需从训练这条重路线起步。 |
| [ManimCode](https://arxiv.org/abs/2611.08294)，2026-11-05 | 保存生成、运行、视觉反馈与修订轨迹；单一模型承担写作、审阅、修改，进一步训练 reviser。 | 保存失败补丁和修复轨迹有价值，但“用修复轨迹训练”也不是空白。其渲染成功率不能直接替代教学质量。 |
| [VibeVideoBench](https://arxiv.org/abs/2610.35864)，2026-10 | 239 个完整音视频代码生成任务，含课堂讲解；交付检查、题目细则和多维 VLM 评价。 | **最新 benchmark 近邻。** 我们应突出跨学科讲解／解题及内容、组织、表达的教学要求，并把交付率与质量分开。 |

### 经验、提示与技能的跨任务演化

| 工作及一手来源 | 持久改变的对象 | 借鉴方式 |
| --- | --- | --- |
| [ManimAgent](https://arxiv.org/abs/2606.30296)，2026-06；v3 2026-10，页面标注 EMNLP 2026 Main | 教育动画 Agent 的跨题正／负经验记忆；不更新模型权重。 | **最接近我们的记忆试验。** 它已比较无记忆、匹配预算检索及打乱记忆。因此必须验证经验的相关性和质量，不能只展示越跑越高的自评分。 |
| [GEPA](https://arxiv.org/abs/2507.19457)，2025-07；v2 2026-02 | 用轨迹反思提出提示修改，评估候选并保留互补方案。 | 可以优化分镜或修复提示，但需独立开发／验证集，固定预算和评分器。提示搜索不自动构成 RSI。 |
| [ACE](https://arxiv.org/abs/2510.04618)，2025-10；v3 2026-03 | 增量积累、整理和修正上下文策略。 | 将经验做成带来源的小条目，支持撤销；避免一次总结覆盖以前的有效约束。 |
| [MUSE-Autoskill](https://arxiv.org/abs/2605.27366)，2026-05 | 创建、存储、检索、评估及改进技能的完整生命周期。 | 每个教学操作需要触发条件、适用范围、失败例及测试，不能只积累口号。 |

### Harness 演化与 RSI

| 工作及一手来源 | 自改的对象 | 与我们当前工作的边界 |
| --- | --- | --- |
| [ADAS](https://arxiv.org/abs/2408.08435)，2024-08 | 元 Agent 搜索以代码表示的 Agent 架构，并保留历史候选。 | 证明可搜索执行机制；外部优化器搜系统不等同于系统自主递归改进。 |
| [SICA](https://arxiv.org/abs/2504.15228)，2025-04 | 编码 Agent 修改自身实现，靠任务结果验证。 | 若未来自动修改修复路由、工具接口、观察策略，才接近这一路线。 |
| [Darwin Gödel Machine](https://arxiv.org/abs/2505.22954)，2025-05 | 自修改代码，保留分支 Agent 档案，用实验筛选后续版本。 | 强调改的是可复用执行系统，并检验后续任务能力；代价和验证要求高。 |
| [Video-RSI](https://arxiv.org/abs/2609.37950)，2026-09 | 视频理解 Agent 主动回看训练视频以区分失败原因，按准确率与观察成本选择 harness 修改。 | **研究对象是理解。** 可借鉴主动补帧与成本感知诊断，但不能作为“教学视频生成 RSI 已有效”的证据。 |
| [VideoEvoHarness](https://arxiv.org/abs/2610.15389)，2026-10 | 从无标注视频共同演化 Questioner／Solver 的策略、技能和工具，固定模型参数。 | 同样主要是视频理解；可借鉴相同验证题比较候选机制。我们的正式 benchmark 题目／评分器不随生成 Agent 演化。 |
| [Video Generation Meets Agent Harness](https://arxiv.org/abs/2610.40191)，2026-10 | 综述 Agent 视频生成、世界模型和 RSI，区分作品修改、状态、参数、评估器及改进过程。 | 用于整理术语和发现文献；它是综述，不是我们方法有效的实验依据。 |

文献结论很清楚：**Code2Video、视觉反思、跨题记忆、技能演化、代码草稿条件视频生成均已有工作。** 值得检验的研究问题是：教学质量能否由可观察、可执行的知识约束来约束生成和修复，而且这种约束能否在新题中复用。这个组合仍需要对比实验确认贡献，不能预先宣称“首个”。
