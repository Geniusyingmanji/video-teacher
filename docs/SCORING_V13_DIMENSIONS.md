# v13：由维度评分推导质量结论

v13 将质量检查归入公开维度，移除 v13 quality_gate 中独立的质量否决条件。v12、legacy-v11 及历史产物保留，使用显式策略可继续复现。基准 CLI 与四卡新任务默认使用 quality-v13；旧结果不会自动改分。

## 维度及归属

- 原八个画质、教学维度：继续使用适用细项的 1–5 分均值线性转换为 0–100 分。
- 教学呈现：布局可读性、视觉解释、时间贡献、表征完整性、教学聚焦、节奏，使用现有呈现评审的细项。若有实际渲染布局诊断，将其作为本维度中的一个可见细项，符合为 100、不符合为 0，与其他细项等权平均；没有诊断不推断失败。
- 任务完整性：有证据的要求覆盖率乘以 100。任何 uncertain 要求使此维度未验证，不将不确定内容当成零分。已确认缺失/错误的要求计入未完成比例。
- 指令遵循：实际时长符合性、适用且已测量的原图保留和教学时间线检查，各作为 0/100 细项等权平均。原图保留包含编码前检查。未测量不构造零分；完全没有测量则维度未验证。
- 英文旁白要求存在时，增加讲解维度：真实音轨评审中的准确性、解释覆盖、音画对应和语速细项均值。实际语音识别证据不足则未验证。

教学组对原五个教学维度与新增三个维度等权平均。画质组保持原三个维度等权。需旁白时组权重为画质 40%、教学 40%、讲解 20%；否则画质、教学各 50%。这些是公开政策选择，尚未进行外部人工效度校准。

## 结论与证据状态

普通维度阈值为 60，概念正确性及教学清晰度为 70，画质组与教学组均为 70。通过状态完全由这些公开分数与阈值推导；旧 review.passed、engagement 检查或另一次关键细项检查不再另行否决。分数不会因阈值失败被封顶或归零。

生成失败/视频不可用单列 unavailable_video；证据冲突未解决、未完成全片检查、语音证据不足或维度缺分单列 unverified。两者总分均为 null；可验证的局部维度保留，视频不可用时所有维度为空。quality_gate 分别返回维度失败 failures 和未验证原因 unverified。生成流程本身的文件与渲染约束保持原有行为。

历史报告仍显示原始策略结果。本次修改不代表新的模型实验或人工全片验收已经完成。
