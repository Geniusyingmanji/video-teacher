# 交互式教学片段：第一版

本地原型把一份教学契约展开成多个可选择的、已验证状态。学生看到初始状态后改变条件，先预测，再揭示状态对应的画面和解释。当前样例是凸透镜焦距；其他学科可提供自己的状态分支、约束和画面图元，播放器无需修改。

```powershell
python -m scripts.build_interactive_lesson
```

用浏览器打开 [`results/interactive/convex_lens.html`](../results/interactive/convex_lens.html)。这是独立 HTML，不需要服务器或视频模型。交互记录可以下载为 JSON；没有上传服务。

## 方法

1. [`data/interactive/convex_lens.json`](../data/interactive/convex_lens.json) 声明三个条件：焦距缩短、保持、加长。每个分支只覆盖知识状态的字段，保留原契约中的教学目标、画面布局和基础断言。
2. 编译器增加“每条出射光线终点等于焦点”的断言，并对每个分支运行 [`validate_contract`](../generation/teaching_contract.py)。错误的光线终点、焦点偏离主轴或不一致的 invariant 会使构建失败。
3. 编译器从同一个经校验的状态渲染预测前、光线传播过程和揭示后的画面。预测前隐藏焦点和折射光线；学生作答后，光线逐帧延伸至焦点。浏览器只播放这些预先生成的画面，不在客户端计算物理事实。
4. 每次揭示记录分支、预测、标准答案、是否正确、时间与契约哈希，便于后续与固定视频、普通分支视频做同题比较。

## 当前对照与边界

| 方法 | 学生能改变条件 | 结果与知识状态绑定 | 目前已有证据 |
| --- | --- | --- | --- |
| 固定视频 | 否 | 无交互状态 | 已有 8 条样片及缺陷审查 |
| 普通分支视频 | 预设跳转 | 尚未接入契约 | 尚未制作对照 |
| 本原型 | 三个预设条件 | 每个结果通过契约检查 | 构建和分支检查通过 |
| 实时生成世界模型 | 连续动作 | 需另建可信状态层 | 尚未试验 |

这一版验证的是**交互架构和状态约束**，不是学习增益，也不是实时像素视频生成。下一轮应先制作相同内容的固定播放与普通分支版本，给真实学生随机分配版本，用相同的前测、后测和延迟测验比较学习结果，同时记录完成时间和操作次数。题目与答案应在生成实验前冻结，避免用某一版本的输出反向定题。
