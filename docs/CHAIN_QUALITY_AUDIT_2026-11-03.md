# 生成与评测链路复核（2026-11-03）

**上次的问题没有全部修复。** 最近一次两卡批次为生成通过 6/10、质量通过 2/10，
不是此前四卡批次的 7/10、0/10。不能把不同批次或评分版本混成一个结果。

本次直接查看了六份成片和一份失败诊断渲染的起始、中间及最终原分辨率帧，并核对生成代码、诊断和评分。
Markov 两处答案现已正确显示为 0.8、0.4；医学视频仍缺流向演示且主体很小；
化学图遮挡说明文字；公民教育视频结尾有重叠文字。历史题有可见对比与高亮，
排序题最终顺序正确，但这些局部事实不能代替全部任务验收。

## 修订后的实际链路

| 阶段 | 代码与作用 | 拒绝什么 |
| --- | --- | --- |
| 当前任务 | `generation/task_requirements.py` 为完整当前 prompt、概念、视觉、顺序及学科 rubric 编号 | 缺少当前任务、把历史题意当现题 |
| 生成约束 | `generation/strict_video_contract.py` 把编号义务传给规划、分镜和修复 | 省略目标、靠文字宣称完成动作 |
| 源图规划 | `generation/source_plan.py` 验证所有操作并确定性编译；几何由代码测量 | 漏操作、错误目标、越界和未核准扩大范围 |
| 几何预算 | 精确计算编辑矩形的并集面积，仍限源图面积的 25% | 重叠框重复计数；让模型猜面积 |
| 渲染 | `generation/strict_manim.py` 分配完整 75 帧并逐帧保护源图；验证科学素材实际入场 | 超时、越界像素、调用素材却未显示 |
| 布局 | `generation/layout_guard.py` 检查稳定状态的文字边界、字号、文字相交及上层不透明图遮挡 | 时长正确但文字不可见 |
| 任务完成 | `eval/task_completion.py` 逐项记录 expected、observed、finding、帧号，再作 verdict | 漏做、做错、无法确认仍称完成 |
| 数值依据 | `eval/numeric_evidence.py` 用 Decimal 计算当前任务的简单算术等式 | 让模型自行臆断 0.2+0.8 的和 |
| 八轴评测 | 严格 schema 的观察和跨轴复核；本地评测使用 temperature=0 | JSON 合法却事实冲突、无依据高分 |
| 同片重试 | `evaluate_with_retry` 对无效评测或附加报告失败最多重试一次，复用有效维度 | 因评测接口故障重新生成整段视频；反复抽分 |
| 验收与反馈 | `quality_gate` 将步骤、终态和逐项完成列为门槛，反馈包含具体失败义务与最新规划拒因 | 用平均分或吸引力抵消漏做和错误 |
| 批次与续跑 | 两卡共享队列、原十题分母、原子写入；续跑匹配提交、全部实现哈希及题目哈希 | 丢失失败题、修改工作区后沿用旧产物 |

版本升级为 `strict-five-seconds-v5` / `video-teacher-2x8-v6`。
八轴权重和通过阈值不变；关键步骤、终态缺失，以及逐项核查中的明确 missing/incorrect，
使用已有严重缺陷政策：正确性轴最多 40，总分最多 50，并禁止通过。
uncertain 会阻止通过，不伪造为“错误”并任意压低分数。
有有效逐项核查时，全图低运动只保留为诊断，动作漏做由任务证据和关键准则处理；
不再因局部变化被全图均值稀释而直接扣分。质量报告同时记录义务覆盖率、失败 ID 和十题分母，数值分数只是一项诊断。

## 实证验证

- 新逐项复核明确拒绝旧医学视频：缺少逐项标签揭示和可见流向，保留具体失败义务与证据帧，不沿用旧 85 分作为通过依据。
- 对 400 题重新做结构预检，400/400 可建立当前 contract，171 题当前任务需要源图。
  题目拥有历史源图元数据不等于当前任务仍要求使用该图。
- 旧化学场景真实重渲染仍为 75 帧、15 fps、5 秒；新布局检测发现两处图像遮挡文字并拒绝。
- 正反对照使用同一个 Markov 当前题目和两段真实视频；错误视频存在错填、漏填，
  正确视频有两个正确答案。初版复核暴露算术幻觉和“先定 verdict 再解释”的矛盾，
  因此补充精确算术依据、先记录证据再判定，以及有界字段，不按本批次统一加减分。
- 完整自动回归 **133 项通过**，覆盖漏做不能被高分抵消、uncertain 不冒充错误、非法证据帧、旧任务隔离、
  精确尾帧采样、矩形并集、图片遮挡、科学素材假调用和同片评测重试。

小型证据保存在 `results/reports/chain_audit_20261103/`；完整视频和运行日志仍在本地。
最终测试数量、正反对照和本轮重跑状态以该目录下的证据文件为准。

通用数学证明器。现有自动判断仍为同模型复核，不是独立专家校准。
本次没有证明 400 题全部语义正确，也不能提前宣布新十题全部质量通过。
