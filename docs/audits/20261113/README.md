## 3. 当前 General 评分的完整路径

1. **冻结任务与来源**：`run.select_cases` 决定分母；公开生成输入与评测任务分开保存。`provenance.freeze_run` 绑定配置及全部 localbench Python 源码哈希，续跑不允许换源码或任务。清单中的成片 SHA256 在评测前核对。
2. **实际成片取证**：`evidence.extract` 解码完整视频计帧，但给评审的是约 24 张均匀帧加三组三帧密集窗口；音频切成不超过约 24 秒的连续片段。解码完整不等于模型逐帧检查完整。
3. **音频独立检查**：`judge.assess_audio` 先做本地 ASR/VAD，再让实际听音模型评六项。`speech.reconcile` 合并语音存在性与转写证据；数字静音、确认无语音和证据冲突分开。音质按音频时长加权。
4. **视觉事实与专项检查**：先看八张帧提取字面观察；再做领域专项 `verification.verify`、屏幕文字与几何关系 `relation_audit.review_relations`。原图 S00 与实际视频帧严格区分。
5. **教学六维**：correctness、completeness、clarity、structure、visual_teaching、audience。`assess_teaching` 校验每维六项，失败维度单独重试，成功兄弟维度保留；参考合同路径还要求逐条 public requirement findings。
6. **画面两维**：`assess_presentation` 独立评 visual_quality、temporal_consistency，不提供题目与答案，减少“缺教学内容”对固有画质的重复扣分。布局检查提供可回查的帧和局部图。
7. **音画配合一维**：`alignment.make_probes` 从真实定时转写构造最多八个局部时窗，只允许引用相应时间附近的画面和音频；不能拿后面的正确画面证明前面同步。
8. **结构与证据校验**：`rubric.validate_scores` 检查固定维度/项目、整数 1–5、真实证据 ID、理由与严重性；未知为 null，有限可选项才允许不适用。代码校验结构和引用存在性，不证明理由在语义上是真的。
9. **证据完整性与汇总**：转写或定时不完整会使相应维度缺分；独立检查与评分冲突会扣留总分。可选 transcript guard 对争议语音做复核，其未解争议也扣留总分。
10. **报告与比较**：`delivery.build_report` 保留所有计划题，报告交付、评分覆盖、有效样本均分和全体均分；`requirements.output_checks` 并列显示要求失败/待核查/未验证。`compare.paired_summary` 以同题有效配对做 bootstrap，Specific 和学生结果不混入 General。

General 十维每维六项，维度分为 `(适用项均分−1)×25`。视频三维等权形成 50%，教学七维等权形成 50%；教学内容/组织/表达在教学组内占 2/7、3/7、2/7。旧 v12/v13 的维度数、组别、权重和验收均不同，不能直接横比。

## 4. 本次已修复且有离线回归证据的问题

### P1：要求清单缺失没有自己的恢复机会

`assess_teaching` 原来只把非法维度放入重试队列；若六维分数完全合法、requirement_findings 缺失，循环直接结束，任务完整性被置为未验证，清单没机会补交。

修复为独立一次清单 schema 重试，使用相同成片与要求上下文，只返回清单，不改写已接受维度分数。仍失败就保留未验证及原始错误。保存修复响应，成功和失败两条回归均验证评分细项不变。此分支额外最多一次评测请求；本次没有发出真实请求。

### P1：同名题号可能误配不同任务

`paired_summary` 原来以 case_id/mode 配对，没有核对两侧 case_hash。CLI 原有 rubric/model 检查也不保护直接调用函数，题目修改后仍可能产生看似同题的差值。

修复为：任一侧提供 case_hash、rubric_version 或 judge_model 时，两侧必须一致，单侧缺失也拒绝。历史双方都缺 task hash 时兼容保留，但显式列入 task_identity_unverified_ids，不能说任务身份已核验。新结果须使用 verified IDs；历史匿名 fixture 不等于正式可比证据。

“高均分但检查失败”在当前明确分开评分与要求诊断时不自动是算术 bug。等权加权意味着，一个教学细项由 5 降到 1，最高只让综合分下降约 1.19 分；一个视频细项的同类变化下降约 2.78 分。是否允许关键错误被均值补偿是协议决定，应在实验前声明，不能看结果后改阈值。

当前视觉评分与音频分数的证据尺度也不同：视觉为固定采样/模型逐项评分，音频按时长汇总；不能用相同数字精度暗示相同测量可靠性。模型返回正确 JSON、通过严重性一致性校验，不代表实际听清或看对。
