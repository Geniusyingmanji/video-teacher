# 1–3 分钟单题教学视频与 v8 评测

题库 `data/prompts/candidate_400_lessons_v1.jsonl` 是独立的教学任务版本，
完整保存每题旧版本和哈希；不覆盖原始 `candidate_400.jsonl`，不恢复可能与当前题意
冲突的历史 original_prompt_text。当前旧题的知识内容、数字、答案约束和禁止事项继续保留。
新任务明确增加可见解释、结果核查和简短回顾；这是任务版本变化，不能与旧五秒成绩
作纯时长因果比较。原图题新增独立讲解区的授权也写入新题。

## 内容和时间

当前 400 题包含 245 道解题、155 道知识讲解，覆盖简单、标准和较难任务。
218 题为 60 秒、169 题为 120 秒、13 题为 180 秒。简单任务和原图操作先用一分钟，
其余默认两分钟，明确标注较难的独立教学任务用三分钟。难度标签沿用题库元数据，
未经过独立难度校准；时长是工程预算，不是已验证的最优教学时间。

解题要求呈现条件、目标、策略、操作理由、中间值/单位以及代回核验。
知识讲解要求用可见对象呈现概念和关系、机制或对照，解释易混点，再回顾意义。
两者都不能依靠答案标签、重复播放、装饰运动或长静止画面充时长。当前不要求音频，
因此图示和短字幕必须能独立解释。

每题先规划连续覆盖完整时长的章节；一分钟至少三章、两分钟至少六章、三分钟至少九章，
每章 3–30 秒，目标和可见证据必须不同，并映射到当前题目要求 ID；所有要求必须被覆盖。
该映射只是规划结构检查，语义正确性仍由实际视频审查决定。
代码必须在章节边界调用 `self.begin_teaching_step(id)`；运行时验证真实时间点和事件总时长。
最多允许 2% 的小量计时校正，不接受把五秒片拉长、截断或补长到目标时长，单次静止等待不得超过八秒。
最终视频严格为 15 fps，对应 900 / 1800 / 2700 个解码帧。

原图完整固定显示在画面上方 60% 高度的参考区；原始像素坐标通过统一 helper 映射。
只允许在经验证目标框中做题目授权修改，目标框并集仍不得超过原图面积的 25%。
下方 65–100% 是单独的讲解区。编码前每帧检查参考区和分隔带是否被非授权修改，
编码后再验证原图和实际视频。正文、字幕和图示仍须通过布局与可读性审查。

## v8 评分

八轴诊断和 v7 呈现门槛继续保留，但历史成绩不重新命名。
分钟级视频逐个十秒窗口以 2 fps 取证，窗口之间向前重叠一秒，保留真实源帧时间戳。
每窗独立审查布局、状态完整性、节奏、可见事件和每项任务要求的局部证据。
任何一个窗口审查失败，都不能宣称整片通过；同一视频的验证重试复用已有效窗口。

局部审查区分某要求在本窗完全满足、部分展示、错误、未出现和不确定。
完整任务核查综合所有窗口，引用具体 segment_id 与局部帧；代码验证这些引用确实来自
该要求已记录的证据。一个窗口没展示后续步骤不自动视为整片缺失，几个部分观察也不
自动等同于完整要求已满足。

整片另用带时间戳的概览帧检查前后衔接，与真实末帧保持版本比较，交换 A/B 次序。
持续严重布局缺陷不能被其他章节或清晰编码平均抵消；内容完成度、正确性和视频带来的
信息都要通过。呈现分限制最终总分，教学吸引力仍单独报告。

窗口抽样仍可能漏掉短暂错误；局部像素变化不能证明推理正确；同模型生成与自评仍可能
误判。此实现没有独立人工校准或真实学习效果实验，不声称十题结果能代表 400 题质量。

## 复现

完成代码检查后生成并冻结十题，选题规则预先公开：四道一分钟、三道两分钟、三道三分钟；
知识讲解和解题各五道，每个时长都覆盖两种类型，包含简单题、较难题和原图操作。
这是覆盖性选择，不是随机抽样；生成失败后不更换题目、不从十题分母中删除。

```bash
python scripts/build_lesson_prompts.py
python scripts/preflight_candidate400.py
python -m unittest discover -s tests -v
python scripts/select_lesson_cases.py
python scripts/run_qwen_multigpu.py --gpus 2 3 --ports 8002 8003 \
  --prompts data/prompts/lesson_validation_10_v1.jsonl \
  --out results/optimization_20261103/lessons10_two_gpu_v1
```

两张 GPU 需要各有一个已启动、支持图片和严格 JSON Schema 的 Qwen 服务。
渲染环境需安装 Manim 和 ffmpeg；本地路径由机器配置决定。
运行目录必须为空，续跑要求任务、实现哈希、提交和评分配置完全一致。
每轮有界重试保留所有证据。生成成功与质量验收分别记录；完整十题结果以
completion.json 和 v8 逐题报告为准，不能用少量有效高分代替十题完成。
