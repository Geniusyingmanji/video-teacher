# 教学呈现评分新规：2x8-v4

## 目的与边界

本版明确评价易懂性、形象化解释，以及可观察的教学吸引力设计。保持现有
八个总分维度与权重，避免把相近概念重复计分。“教学吸引力”单独报告，
不计入总分、不改变通过门槛，不以趣味性补偿知识错误。

当前代理评分依据抽样视频帧，不能证明学生实际感到有趣、理解了或学会了。
5 秒视频按真实时长和目标受众判断，不能假设无限暂停、额外讲解或背景知识。
无音频输入时不得推断配乐、语音感染力或旁白质量。

## 易懂性：教学清晰度内强化

在 `pedagogical_clarity` 的六个子项中评分，不新增等权总分轴：

| 子项 | 评价依据 |
| --- | --- |
| single_focus | 目标受众能识别当前问题和单一学习目标，无需补全缺失情境 |
| attention | 关键对象在正确时刻受到强调，没有竞争性高亮 |
| explanation | 画面展示结果如何或为何成立；要求解释机制时，仅亮出答案不足 |
| readability | 按实际时长看得清、读得完、跟得上关键变化 |
| ambiguity | 初态、操作、结果和符号对应明确 |
| takeaway | 结尾直接传达任务结论，不依赖画外解释 |

例如，五秒内堆放多行长公式，即使逐帧能读清，也不能因此获得阅读时间高分。

## 形象化解释：教学可供性内强化

在 `didactic_affordances` 内评分，重点区分“画面好看”和“知识关系被展示”：

| 子项 | 评价依据 |
| --- | --- |
| observable_change | 具体表示使关键状态、关系或前后变化可见 |
| step_evidence | 关键操作、机制或关系被演示；不能只有说明文字 |
| reference_anchor | 稳定对象、尺度或对应关系支持比较 |
| alignment | 图形、位置、箭头、颜色、标签与知识关系准确对应 |
| inspectability | 能暂停定位并核对结果 |
| diagnosability | 错误答案或操作能从画面中被辨认 |

按任务适用性评分：填概率题中，正确定位的标注就可以充分完成任务，不强求
额外机制动画；要求三角形角片拼接成平角时，仅显示“180°”则不是充分演示。
不强求比喻、拟人、卡通、写实或三维。比喻一旦使用，必须保留相关关系。
清晰度判断“能否跟上”，教学可供性判断“表示是否显露知识关系或操作”。

## 教学吸引力：独立附加报告

字段为 `supplementary.teaching_engagement`，版本 `teaching-engagement-v1`。
六个子项各按 1–5 分评价：

| 子项 | 评价依据 |
| --- | --- |
| task_relevance | 引导注意的内容直接服务任务 |
| attention_invitation | 有可理解的关注对象或目标；简明问题本身即可成立 |
| meaningful_progress | 有值得跟随的变化、比较或揭示；合理静态停留不扣分 |
| perceptual_salience | 关键区别和结果突出，视觉竞争低 |
| coherence | 无抢占注意的无关元素，强调服务知识 |
| audience_fit | 呈现方式适合受众和题材；严肃、极简不是缺陷 |

预测问题、故事、角色、配乐、丰富颜色不是必选项，其缺席不扣分，出现也不
自动加分。准确、简洁、重点突出的普通示意图可以高分。不能把“看起来可能
吸引注意”表述为“学生实际喜欢”。

## 统一分数锚点与证据

| 分数 | 含义 |
| --- | --- |
| 1 | 明确严重失败，例如关键关系错误或无关装饰掩盖任务 |
| 2 | 明显不足，关键解释或注意线索缺失 |
| 3 | 部分实现或证据不确定，不能假设缺失步骤存在 |
| 4 | 有清晰可定位的有效设计证据，存在轻微限制 |
| 5 | 在该任务、受众和时长内有充分且一致的有效设计证据 |

每个子项返回适用性、分数、证据帧号和具体理由。3 分及以上必须引用有效
证据帧；至少四项适用才给维度均分。不适用不能作为逃避要求的理由。
分数映射为 `(适用项均分 - 1) × 25`，范围 0–100。

附加评分失败不修改八维总分，但单独标记缺失。总览包含覆盖率与失败数；
只有全部样本的附加评分有效时才输出 `mean_complete_only`。部分样本均分
只能写入明确标注的 `diagnostic_mean_available_only`。批次完成要求十题均有
有效八维评分和有效附加评分。分数阈值尚不是经真人实验校准的兴趣尺度。

## 版本与重跑

- 总协议：`video-teacher-2x8-v4`；教学子项：`6x6-v2`。
- 全部八维重新评测同一批成片，附加教学吸引力评分；不能只把新分附到旧总分。
- 版本和评分代码哈希进入恢复缓存校验；旧版分数不得复用或混算。
- 十题试跑结果写入独立 `video-teacher-2x8-v4/` 目录；保留旧结果。
- 沿用 GPU 0 本地 Qwen，自评结果需标明同模型自评，不能作独立效度证据。

```bash
/root/code2video-env/bin/python -u scripts/run_qwen_sample10.py
```

此命令复用通过严格五秒验收的成片，继续尚未完成的生成，最后运行新版评分。
正确性、源图保护和严格五秒生成要求不因本版评分而放宽。

若生成批次仍在运行，可单独启动新版重评跟随任务：

```bash
/root/code2video-env/bin/python -u scripts/reevaluate_qwen_sample10.py
```

它先评已有成片，每当生成清单更新就继续评测，复用同版有效评分；全程保留
十题分母，尚无成片的题目明确记为缺失。输入清单快照、逐题结果、附加评分
覆盖率与 `reevaluation_status.json` 均保存在版本目录中。十题生成均结束但有
失败时，任务保留不完整状态并以非零退出，不声称完成十题新规评测。
