# 评分链路修复：2026-11-04

本次修复评分执行与可追溯性，不改变 v11 评分标尺，不统一加减分，不覆盖旧报告。

## 已复现的故障

- 当前本地 xgrammar 对 `multipleOf: 0.5` 返回 HTTP 400。三个评分 schema 改为等价枚举 `1, 1.5, …, 5`；保留本地数值、引用、重复项目与完整性校验。
- 实际 ASR 时间戳可能是 NumPy 实数，旧代码要求精确的 Python `int/float` 类型，导致合法证据被拒绝。现在在 ASR 输出处序列化为 Python 浮点数，测量入口接受有限实数，继续拒绝布尔、NaN、无穷和倒置区间。
- 完成度审查或一致性审查异常会跳过后续独立维度。现在隔离各审查阶段，继续保留其他已验证结果；缺少必要审查时，总分仍不生效。
- 缓存不再复用失败的任务完成度审查。有效低分不会因不及格而重试；只对执行或验证失败做有界重试。
- 旧客户端设置 300 秒超时，且 SDK 与外层均重试，可能重复执行长回复；所有连接类异常还被误报为 429。现在超时默认 900 秒，可通过 `VIDEO_TEACHER_JUDGE_TIMEOUT_S` 配置；SDK 重试为 0，由外层统一限制最多 3 次请求，日志记录真实异常类型和 HTTP 状态。
- 结构化 rubric 先要求实际观察与帧引用，再给适用性和分值。缩短描述的长度限制，不减少逐窗口要求核查、数值合法性或证据校验。

## 输出与恢复

每条结果和汇总包含 `assessment_coverage`：八个维度、呈现质量、任务覆盖率、教学参与设计、必要旁白评估及总分均有状态、分值和失败原因。任务覆盖率明确为 0..1，与 0..100 质量分区分。

`scored` 表示存在经对应模块校验的分值；`unavailable_video` 表示没有可用成片；`evaluation_failed` 表示证据或评估未验证。后两种保持 `null`，不伪装成 0 分。

CLI 增加 `--workers` 和可重复的 `--judge-base-url`。独立进程隔离服务配置，父进程逐条写入结果，结束后按原任务顺序整理。长成片优先调度，避免排在队尾延长整体等待。每条结果记录实际评委地址、模型、视频摘要、任务摘要、代码摘要与采样参数；恢复时核对身份和摘要。

ASR、每个时间窗口和每个维度完成后，原子写入 `checkpoints/`。中断后只复用来源、代码和配置完全匹配的证据，失败窗口继续重试。完整原始窗口记录保留；后续模型上下文将重复的 `not_shown` 记录压缩为明确的未展示要求 ID，保留所有实际观察、错误和不确定记录。未展示从不等于满足要求。

## 证据与限制

- 画面评估使用实际解码帧、十秒窗口、局部帧引用及时间戳。
- 旁白审查使用实际音轨的 ASR，而非计划中的旁白稿。ASR 不等于直接听音或发音质量认证。
- 数值由固定 rubric 与聚合代码计算；缺证据、非法引用、重复条件和截断响应不得变成有效总分。
- 当前本地评委与生成模型均为 Qwen3.8-27B，属于同模型自评。证据校验不能证明每条模型观察必然正确，也不能替代独立人工或跨模型校准。
- 未生成成片的任务不能取得真实的视频质量分；必须先修复生成，再重评。不能为了填满表格制造数值。

## 继续修复与复评（2026-11-04）

- 三分钟案例触发本地 32768-token 上下文限制，多个下游维度因 HTTP 400 无法执行。新增 `evidence_prompt.prompt_json`，用带列名的表格编码重复的逐要求观察字段，并去掉 JSON 空白。所有状态、观察文本、引用和时间戳原样保留，原始报告仍保存对象结构。
- 复核跟踪器按基础结果摘要识别更新；基础汇总记录 `per_case_sha256`，跟踪模式必须等待与当前结果一致的汇总，防止旧行数触发提前结束。
- 不复用 `uncertain` 的严重缺陷核查检查点；事实未确认时总分仍无效。
- 重新计算已纠正的分数时保留实际音轨的节奏诊断，不从诊断阈值自动扣分。
- 新一轮输出目录为 `compact_final/`，严重缺陷复核目录为 `compact_verified/`。旧的 `final/` 与 `verified/` 保留作为故障与修复过程证据，不代表最终验收。

本轮仍沿用固定十题和原成片，不替换五条失败生成记录。流程执行完成与十题全部生成、质量达标分别报告。

## 复核图片预算与过渡帧检查

实跑中一条指控引用 23 张原帧，旧复核又追加 23 张裁剪图，超过服务的 24 张图片限制。现在保留全部原帧，裁剪只使用剩余图片配额；观察输出预算随原帧数量增长。

局部缺陷核查为每个被引用时刻补充前后至少一秒的最近采样帧，检查稳定状态。两个独立字幕过渡中的叠字不证明持续严重缺陷；缺少可核实证据时仍保持 `uncertain`，不能填入有效总分。原始要求、v11 评分公式和扣分门槛不变，复核实现版本为 `localized-claim-grounding-v2-settled-neighbors`，结果版本为 `video-teacher-2x8-v11+grounded-v2`。

最终复核目录更新为 `compact_verified_v2/`。`compact_verified/` 保留图片超限等修复前结果。基础评估仍在 `compact_final/`，48 个窗口来源和代码摘要已通过离线审计。完整测试更新为 214 项通过。

## 报告一致性与视频正确性分离

排序案例的八个维度报告均描述了错误终态，旧一致性审查却因为视频终态错误而把所有报告判为互相矛盾。新增逐语句一致性复核：按维度和条目固定键逐一检查原报告，每条结论绑定原文与实际帧引用，区分客观一致、非实质质量意见、实质事实冲突及无法验证。语句摘要参与完整性校验，离线审计重新核对原文、引用和有效性。

有实质冲突或无法验证的语句仍阻断总分。准确描述错误视频的报告可得到有效低分，原错误答案、任务遗漏、呈现质量和旁白门槛继续按原公式计算。实际音轨 ASR 独立提供语音文本证据，不以计划中的配音稿替代。旧一致性审查与旧分数保存在原结果及 `base_evaluation` 中。

最终复核实现更新为 `video-teacher-2x8-v11+grounded-v3`，产物目录为 `compact_verified_v3/`。此前 v1/v2 复核目录均作历史记录保留。
