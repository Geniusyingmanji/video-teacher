# Code2Video 四卡评分与后续八题生成

先对线性变换与矩阵成片执行四次完整 quality-v12 评测，每卡一次。评测同一视频、同一冻结任务，独立保留结果，不当作四个样本，不挑最高分。按本项目规则要求英文口述；原作者成片无音轨，该缺项不会被移除。未知评分保持 null。

每次评测覆盖全部十秒窗口，再执行整体八轴、任务覆盖、呈现、事实一致性与旁白检查。四次都完成全片窗口检查后，才开始八道作者题单主题生成；过程失败或窗口缺失时暂停批次。

生成使用四个本地 Qwen 副本，端口 8000–8003，每卡两题并发。保留作者 Planner/Coder/Critic，原 API 模型换为 Qwen，Critic 原生视频输入换为有序抽帧，可选外部图标关闭。不代表原 API 模型成绩或完整论文基准复现。

运行目录：`results/code2video_scored_batch_20261110/`；state.json 记录阶段，eval_gpu0.log 至 eval_gpu3.log 记录评分，score_summary.json 保留四次结论，case_01.log 至 case_08.log 记录生成。
完整生成且解码通过的最终视频单独交付到 `delivery/最终视频/Code2Video_新增8题_20261110/`，不混入渲染缓存。渲染成功与质量验收分开。

恢复注意：顶层编排器目前是一次执行入口，不可直接重启以免重复提交生成。各阶段已有评测检查点与单题 --resume 入口，需先核实 state.json 和活跃进程。
